
\section{Conclusiones}

El desarrollo de esta practica se llevo acabo gracias al tutorial de raspberry pi de la facultad \cite{FI_UNAM_Raspberry_2026} y a las clases del profesor moises \cite{Melendez_Reyes_2026}.

\subsection{Hernandez Acosta Mauricio Gabriel}
En esta práctica se aprendió a controlar salidas digitales de una tarjeta programable utilizando MicroPython y el IDE Thonny. A través de distintos ejercicios se configuraron pines GPIO para encender y apagar LEDs, modificar tiempos de retardo y generar diferentes secuencias de iluminación, incluyendo patrones progresivos, conteos binarios y la simulación de un sistema de semáforos. Estas actividades permitieron comprender la relación entre el programa y el comportamiento del hardware, así como reforzar el uso de estructuras de control y temporización en sistemas embebidos.

\subsection{Perez Olvera Alexis Abraham}
En la presente práctica trabajamos con la microcomputadora Raspberry Pi utilizando código en MicroPython, con el objetivo de comprender la lógica y funcionamiento de los pines de propósito general de entrada y salida (GPIO). A través de distintos ejercicios se configuraron y controlaron estos pines empleando LEDs como dispositivos de salida, implementado diferentes secuencias de encendido y apagado.
Estas actividades permitieron comprender cómo interactúa el software y el hardware mediante los GPIO, así como identificar posibles aplicaciones prácticas como la implementación de semáforos, máquina de estados y generación de secuencias lógicas. De esta manera,la práctica permitió fortalecer la comprensión del control básico de dispositivos externos mediante programación de hardware.

\subsection{Sierra Garcia Mariana}
En esta práctica se logró conocer el funcionamiento básico de la plataforma Raspberry Pi Pico y el uso de sus pines GPIO como salidas mediante programación en MicroPython utilizando el IDE Thonny. A través de los diferentes ejercicios se desarrollaron algoritmos para controlar el encendido y apagado de LEDs, generar secuencias, implementar contadores binarios y simular el funcionamiento de un sistema de semáforos. Estas actividades permitieron comprender cómo interactuar con el microcontrolador RP2040 y cómo utilizar retardos y estructuras de control para manipular señales digitales en aplicaciones básicas de sistemas embebidos.
